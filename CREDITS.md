# Credits

Almost all of this app is other people's work. Concord is a wrapper and a sync engine around an app
that was already good; the honest credit list is short on this project's own name and long on
everyone else's.

## The apps it is built on

- [Mochy Music](https://github.com/realidkroo/Mochy-Music) — by Roo and key; the app Concord forks
  directly: the player, the screens, the effects, the module system and the library design are its work.
- [Mocha Music](https://github.com/aethux/Mocha-Music) — Aeth's Apple-Music-centric fork of Mochy;
  the reference Concord ports its Apple Music work from.
- [ViviMusic](https://github.com/vivizzz007/vivi-music) by vivizzz007 — the base app Mochy grew from.
- [Metrolist](https://github.com/mostafaalagamy/Metrolist) by Mostafa Alagamy — the base framework.

## The libraries and services it leans on

- [SimpMusic](https://github.com/maxrave-dev/SimpMusic) by maxrave-dev — lyrics API provider.
- [ArchiveTune](https://github.com/rukamori/ArchiveTune) by Rukamori — design and architecture
  inspiration.
- [RiMusic](https://github.com/fast4x/RiMusic) by fast4x — YouTube Music InnerTube wrapper.
- [LRCLib](https://github.com/tranxuanthang/lrclib) by tranxuanthang — synchronized lyrics.
- [Monochrome](https://github.com/monochrome-music/monochrome) — FLAC streams.
- [InnertubeX](https://github.com/metrolistGroup/innertubex) by nyxireal — YouTube API access.
- [AutoEq](https://autoeq.app) — the equalizer database. [lrc.red](https://lrc.red) — word-timed
  lyrics.
- LyricsPlus, Better Lyrics API and SimpMusic Lyrics — the free lyric backends.

Apple Music, YouTube Music and Last.fm are not affiliated with this project. Their names appear only
to say what the app talks to. No music is hosted or distributed here; every stream comes from the
service you already subscribe to.
